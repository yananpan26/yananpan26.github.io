# Pan Research Group

Static six-page website hosted on GitHub Pages. Open index.html or serve the repository with a local HTTP server; no build step is required.

- Home: About, CV download, three research interests and News.
- People: faculty and student profiles, portraits and education.
- Research: three research areas.
- Publications: selected papers and Google Scholar.
- Lab: space for future equipment information.
- Contact: Fall 2027 openings and contact details.

Shared design uses self-hosted Arvo fonts, a dark mineral-texture header and blue accents. Portraits have consistent 4:5 display windows. The homepage research section uses three columns on desktop and stacks on mobile, with a title, conceptual illustration and short paragraph for each area.

The research graphics are AI-generated conceptual illustrations, not experimental results. Functional Materials uses the owner-selected complex crystal/layer image; the other two use graphical abstracts rather than laboratory scenes. Artwork and content provenance are recorded in SOURCES.md.

The owner-supplied CV is documents/Yanan-Pan-CV.pdf. Replace it to update the download. Navigation is repeated across all six HTML files. GitHub Pages configuration: main branch, repository root.
